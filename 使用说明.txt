厦园新手村·一站式导航｜版本 4.1（hash 路由 + 统一导航）

1. 请先完整解压本文件夹，保持 assets、pages 与主 HTML 在同一层级。
2. 请打开本文件夹内的：
   厦园新手村·一站式导航.html
3. 不要只复制主 HTML，也不要直接在压缩包内打开；只复制 HTML 会导致图片和栏目页面找不到。
4. 资料存放区仍必须通过 server.py 启动后使用（见文末说明），其余栏目双击主 HTML 即可使用。
5. 全站正文搜索依赖 assets/search-index.js 索引文件（双击直开同样可搜）。各内容页的小节标题均已带稳定锚点 id（由 tools/add_heading_ids.py 生成，已有 id 不会被改动），搜索结果可直接跳到具体小节并显示提示圈。页面内容更新后，请按顺序运行一次 `python3 tools/add_heading_ids.py` 和 `python3 tools/build_search_index.py`，否则新增内容搜不到、也定位不到。

本版（4.1）相对 4.0 的结构性改动：
1. 新增 hash 路由：切换栏目时地址栏会变成 #/page6 这样的地址；刷新后停留在原栏目，浏览器返回/前进键可在栏目间回退，任何栏目都可以复制链接直接分享给同学。
2. 支持锚点深链接：#/page16?anchor=calendar-vacation 这类地址会在页面加载后自动定位到对应小节；搜索结果的“正文匹配/直接回答”点击后同样写入地址，可收藏、可转发。
3. 统一导航入口：侧边栏木牌、总览分区卡片、全局搜索结果、通行码解锁后的跳转，全部走同一个 navigate 入口（village-router），切换行为完全一致。
4. 栏目清单单一数据源：侧边栏分组、总览分区卡片、内容页 iframe、通行码白名单、侧边栏小怪头像，全部由 assets/nav-data.js 生成。新增或调整栏目只需要改 nav-data.js 一处（名称、描述、图标、页面文件、?v= 版本号、是否需要通行码都在这份清单里）。
4b. 正文搜索改为构建期索引：旧版搜索靠运行时读取 iframe 内容，双击直开（file://）时被浏览器拦截、未加载的栏目会被跳过、失败结果还会被永久缓存，导致“四六级”这类只存在于正文链接里的内容搜不到。现在由 tools/build_search_index.py 预先生成 assets/search-index.js，搜索直接查索引，所有栏目、所有打开方式一致可用。
5. 通行码白名单不再两处手工维护：锁定/公开由 nav-data.js 中每项的 public 字段决定；在未解锁状态下点击锁定栏目或打开锁定页深链接，会弹出通行码框且不切换内容，解锁成功后自动进入刚才的目标页。
6. 新增全局顶栏（全站常驻）：内容区顶部有「厦园新手村」品牌标识（松鼠村标 + 名称，点击回到总览）和全站搜索框。在任何栏目页都可以直接搜索，结果以下拉浮层展示（与搜索框对齐的干净纸面卡片），点击结果直接跳转并定位正文；Esc 或点击空白处收起浮层。原总览页内的搜索面板已并入顶栏。
7. 搜索跳转带正文提示圈：命中正文位置时，页面滚动到目标后，目标标题会以琥珀色描边光圈脉冲标记约 5 秒后自动淡出，直接指出要找的内容在哪；结果浮层里「直接回答」类条目的答案摘要在点击前即可预览。
8. AI 小助手入口已移入顶栏并带文字标注（像素小怪 + 「AI 小助手 / 提问 · 快速找答案」）：任何页面点按即可展开问答面板，面板从顶栏右侧下拉；与搜索浮层互斥，切换栏目、点击空白处或按 Esc 均会收起。原右下角的悬浮小怪按钮已移除。
9. 使用提醒：切换栏目后地址栏的 hash 可以直接复制分享；若分享的是锁定栏目地址，对方解锁后即可直达。
10. 站点结构为三大板块（侧栏仅此三项）：「课表」——导入课表（粘贴文本自动解析）后显示整周课表与教学周；「校园资料」——全部攻略按分区浏览、点卡片进入（具体攻略页不再出现在侧栏，深链接仍然有效）；「美食资讯」——食堂与周边美食板块（内容整理中，欢迎投稿，名单以实际开放为准）。打开网站默认落在「校园资料」。
11. 注意：assets/nav-data.js 与 assets/search-index.js 通过 ?v= 参数控制缓存，更新这两个文件后请同步修改主 HTML 里对应 script 标签的 ?v= 版本号，否则老访客拿不到新数据。

版本记录：本文件夹为「厦园新手村」版本 4.1，由 4.0-方案B预览 结构化升级而来；后续更新请按 4.2、4.3……顺延。
